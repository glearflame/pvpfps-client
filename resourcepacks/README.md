# Resource Packs PvP (16x/32x)

Esta pasta e um placeholder para packs PvP leves.

Sugestoes para desempenho/visibilidade:
- Low Fire Pack
- Short Swords Pack
- Clean GUI Pack
- 16x PvP Pack
- 32x PvP Pack

Como usar:
1. Coloque os `.zip` dos packs aqui.
2. Abra o Minecraft > `Opcoes` > `Pacotes de Recursos`.
3. Ative os packs na ordem desejada (Low Fire/Short Swords acima do pack base).
